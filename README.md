# Expense Tracker

A lightweight browser-based expense tracker for recording, organizing, and reviewing personal spending.

## Features

- Add and manage expense records
- Organize expenses by category
- Review spending information in a clear interface
- Runs entirely in the browser with no build step required

## Technology

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

```bash
git clone https://github.com/sameer-softengs/Expense-Tracker.git
cd Expense-Tracker
```

Open `index.html` in a modern browser, or serve the directory with a local static server.

## Project Files

- `index.html` — application layout
- `script.js` — expense-tracking behavior
- `style.css` — interface styling
